# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.2.x | Yes |
| Older than 1.2 | No |

Security fixes are released for the latest 1.2.x version.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email
[security@openpush.ai](mailto:security@openpush.ai), or open this repository's
**Security** tab, choose **Advisories**, then **Report a vulnerability**.
Include the affected version, a minimal reproduction, impact, and any suggested
mitigation.

Never include device credentials, provider tokens, SDK keys, or personal data
in a report.

We aim to acknowledge reports within 3 business days. We will keep you informed
while we validate the report and prepare a fix, and coordinate disclosure with
you. Please wait for a fix or mitigation to be available before disclosing the
issue publicly.
